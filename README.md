# Dobot Kit

Python-библиотека для классического четырёхосевого **DOBOT Magician**. Работает через последовательный USB-порт с Python 3.11 или новее. Текущий предварительный выпуск — **0.3.0a1**.

[Справочник API](https://art9762.github.io/dobot-kit/api.html) · [Поведение и диагностика](https://art9762.github.io/dobot-kit/behavior.html) · [USB-протокол](https://art9762.github.io/dobot-kit/protocol.html) · [Начало работы](https://art9762.github.io/dobot-kit/guide.html) · [История изменений](https://github.com/art9762/dobot-kit/blob/v0.3.0a1/CHANGELOG.md)

## Первый вызов

Включи робота, подключи USB и освободи порт в DobotStudio или другой программе. В активном окружении Python установи пакет и найди назначенный системе порт.

```sh
python -m pip install dobot-usb==0.3.0a1
python -m serial.tools.list_ports
```

Сохрани код в файл `robot_test.py`, подставь точное имя порта и запусти `python robot_test.py`.

```python
from dobot_usb import Dobot

robot = Dobot("COM3")
print(robot.position())
robot.close()
```

Скрипт читает четыре числа `(x, y, z, angle)`. Координаты выражены в миллиметрах, угол в градусах. [Настройка окружения, выбор порта и рабочие примеры](https://art9762.github.io/dobot-kit/guide.html)

## Справочник

| Вызов | Что делает |
| --- | --- |
| `Dobot(port)` | Открывает указанный порт и проверяет ответ чтением позиции. |
| `position()` | Возвращает текущие XYZ и угол. |
| `move(x, y, z, angle=None)` | Перемещает по прямой в абсолютную точку. При пропущенном угле сохраняет текущий. Ждёт индекса и сверяет координаты. |
| `speed(percent)` | Задаёт один процент для скорости и ускорения PTP, от 1 до 100. |
| `home()` | Запускает поиск исходного положения и ждёт исполнения в очереди. |
| `suction_on()`, `suction_off()` | Управляют выходом присоски. |
| `gripper_open()`, `gripper_close()`, `gripper_off()` | Открывают, закрывают или отключают управление схватом. |
| `stop()` | Принудительно останавливает и очищает очередь. |
| `close()` | Освобождает порт. |

Перед первым управляющим действием библиотека останавливает и очищает предыдущую очередь контроллера. Открытие соединения читает координаты. `stop()` управляет очередью, `close()` освобождает порт, а за выходы оснастки отвечают отдельные методы. [Полные сигнатуры, побочные эффекты и ошибки каждого вызова](https://art9762.github.io/dobot-kit/api.html)

## Совместимость и переход

Версия 0.3.0a1 заменяет прежний API. Программы от 0.2.0a4 требуют переноса. Поддерживаются линейное движение, homing, присоска и пневматический схват. Определение модели и выбор оснастки остаются за оператором.

Тесты используют имитацию USB. Достижение цели в тесте означает, что библиотека правильно обрабатывает данные контроллера. Проверка текущей версии на физическом Magician ещё открыта. [Совместимость, миграция и границы проверки](https://art9762.github.io/dobot-kit/development.html)

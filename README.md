# Dobot Kit

Python-библиотека для классического **DOBOT Magician**. Подключаешь руку по USB, читаешь позу и вызываешь методы нужной насадки. Координаты задаются в миллиметрах, повороты — в градусах.

[Документация](https://art9762.github.io/dobot-kit/) · [Примеры Python](examples/) · [Скачать версию 0.2.0a2](https://github.com/art9762/dobot-kit/releases/tag/v0.2.0a2)

## Первые 15 минут

### 1. Установить · 2 минуты

В окружении Python 3.11 или новее установи готовый пакет из GitHub одной командой.

```sh
python -m pip install https://github.com/art9762/dobot-kit/releases/download/v0.2.0a2/dobot_kit-0.2.0a2-py3-none-any.whl
```

Подключи Magician по USB и посмотри, какой порт ему назначила система.

```sh
dobot ports
```

На macOS и Linux команда Python может называться `python3`, на Windows — `py`. Если Python просит отдельное окружение, создай его через `python -m venv .venv`, затем активируй через `source .venv/bin/activate` или `.\.venv\Scripts\Activate.ps1` в Windows PowerShell.

`dobot ports` показывает кандидатов. Скопируй поле `device` своей руки, например `COM3` на Windows или путь `/dev/cu.…` на macOS. Если список пуст, проверь кабель USB и наличие порта в ОС. Известный порт можно указать вручную. Если рук несколько, первый раз подключи их по одной и подпиши порты.

### 2. Узнать положение · 3 минуты

Освободи порт в DobotStudio или пульте. Сохрани программу как `arm.py` и выполни `python arm.py`.

```python
from dobotkit import Dobot

port = input("Порт руки: ").strip()
with Dobot.connect(port, read_only=True) as arm:
    state = arm.status()
    print("Прошивка:", state.device.firmware)
    print("XYZ, мм:", state.pose.x, state.pose.y, state.pose.z)
    print("Ошибки:", state.alarms)
```

Ты увидишь координаты именно этой руки. Пустой кортеж `()` означает, что контроллер не сообщает ошибок. Ту же проверку из терминала делает `dobot status --port COM3` со своим портом.

### 3. Запомнить позу и вернуться · 4 минуты

Для первого движения освободи пространство над инструментом и убедись, что старая очередь больше никому не нужна. Пример рассчитан на свободную руку со стандартной прошивкой и выключенными выходами. Сохрани его как `move.py` и запусти `python move.py`. Рука поднимется на 2 мм и вернётся в запомненную позу.

```python
from dobotkit import Dobot

port = input("Порт руки: ").strip()
with Dobot.connect(port) as arm:
    arm.stop(clear=True)  # Отбросить прежние задания перед новым сеансом
    with arm.motion.sequence():
        start = arm.pose()
        arm.speed(mm_s=5, mm_s2=10)
        arm.move_by(z=2)
        print("Z до и после подъёма:", start.z, arm.pose().z)
        arm.move_to(start)
```

`move_by` задаёт смещение, `move_to` принимает сохранённую позу или координаты XYZ. `sequence()` связывает несколько действий в одно задание: остановка прерывает его и между точками. Скорость, заданная через `speed()`, сохраняется в контроллере. [Скорости и движение](docs/MOTION.md)

### 4. Выбрать инструмент · 6 минут

| Что установлено | Что можно сделать из Python | С чего начать |
| --- | --- | --- |
| Присоска | `arm.suction.pick_and_place(pick, place, lift_mm=10)` переносит предмет между обученными точками | [Перенос между двумя обученными точками](examples/pick_and_place.py) |
| Пневмосхват | Тот же вызов через `arm.gripper.pick_and_place(...)`. Губками можно отдельно управлять через `open()` и `close()` | [Захват и перенос](examples/gripper.py) |
| Держатель пера | `arm.pen.draw(strokes, origin=paper)` рисует XY-штрихи с подъёмом между ними | [Два штриха на листе](docs/MOTION.md#перо-на-плоском-листе) |
| Лазер | `arm.laser.arm()` разрешает включение, `on()` и `off()` управляют выходом | [Работа с лазерной головкой](docs/TOOLS.md) |
| Головка 3D-печати | В режиме принтерной прошивки `Printer.connect(port)` открывает соединение, `printer.print_file("part.gcode")` отправляет нарезанный файл | [Печать из Python](docs/PRINTING.md) |

Для пера `paper = arm.pose()` запоминает положение кончика при лёгком касании листа. Две линии длиной 5 мм задаются так:

```python
strokes = [[(0, 0), (5, 0)], [(5, 3), (0, 3)]]
report = arm.pen.draw(strokes, origin=paper, lift_mm=3)
print(report.completed_points)
```

Этот фрагмент выполняется внутри открытого соединения. Метод закончит рисунок с поднятым пером. `dry_run=True` выполняет реальный пробный проход **над** бумагой. Для проверки координат без движения используй `pen_path(...).preview()`. [Выбор насадки и настройка её смещения](docs/TOOLS.md)

## Когда что-то пошло не так

- **Порт занят или рук несколько.** Закрой программу, которая держит порт, и проверь соответствие по `dobot status --port …`. Каждой руке нужен собственный клиент. [Две руки в одном скрипте](docs/API.md#несколько-рук)
- **История очереди неизвестна.** Начни с чтения состояния. Первая запись в очередь может запустить оставшиеся движения. Вызывай `stop(clear=True)`, только когда предыдущее задание можно отбросить.
- **Команда получила таймаут.** Сначала выясни состояние руки. Если контроллер уже принял движение, повторная отправка может выполнить его дважды. `arm.stop()` запрашивает остановку и очистку очереди по действующей связи. Выход из `with` освобождает порт. Инструменты выключаются отдельно. [Остановка, ошибки и ожидание](docs/EXECUTION.md)

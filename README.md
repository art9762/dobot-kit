# Dobot Kit

Python-библиотека для классического четырёхосевого **DOBOT Magician**. Работает через последовательный USB-порт с Python 3.11 или новее. Текущий предварительный выпуск — **0.3.0a3**.

[Справочник API](https://art9762.github.io/dobot-kit/api.html) · [Поведение и диагностика](https://art9762.github.io/dobot-kit/behavior.html) · [USB-протокол](https://art9762.github.io/dobot-kit/protocol.html) · [Начало работы](https://art9762.github.io/dobot-kit/guide.html) · [История изменений](https://github.com/art9762/dobot-kit/blob/v0.3.0a3/CHANGELOG.md)

## Первый вызов

Включи робота, подключи USB и освободи порт в DobotStudio или другой программе. В активном окружении Python установи пакет и найди назначенный системе порт.

```sh
python -m pip install dobot-usb==0.3.0a3
python -m serial.tools.list_ports
```

Сохрани код в файл `robot_test.py`, подставь точное имя порта и запусти `python robot_test.py`.

```python
from dobot_usb import Dobot

robot = Dobot("COM3")
print(robot.position())
origin = robot.calibrate()  # Только сохраняет точку, не двигает руку.
print("Начало отсчёта:", origin)
robot.close()
```

Скрипт читает четыре числа `(x, y, z, angle)`. Координаты выражены в миллиметрах, угол в градусах. [Настройка окружения, выбор порта и рабочие примеры](https://art9762.github.io/dobot-kit/guide.html)

## Справочник

| Вызов | Что делает |
| --- | --- |
| `Dobot(port)` | Открывает указанный порт и проверяет ответ чтением позиции. |
| `position()` | Возвращает текущие XYZ и угол. |
| `calibrate(position=None)`, `origin` | Запоминает текущую или переданную точку, возвращает её; `origin` читает сохранённую точку без USB. |
| `move(x, y, z, angle=None)` | Перемещает по прямой в абсолютную точку. При пропущенном угле сохраняет текущий. Ждёт индекса и сверяет координаты. |
| `set_x(x)`, `set_y(y)`, `set_z(z)`, `set_angle(angle)` | Перемещает одну ось в абсолютную координату; остальные текущие координаты сохраняются. Калибровка не нужна. |
| `move_x(offset)`, `move_y(offset)`, `move_z(offset)`, `move_angle(offset)` | Задаёт одну ось как сохранённое начало + офсет; остальные текущие координаты сохраняются. |
| `move_relative(dx=0, dy=0, dz=0, dangle=0)` | Задаёт все оси относительно сохранённой калибровки. Повторный вызов не накапливает офсет. |
| `draw_line(start, end)` | Отрезок между абсолютными точками. Сначала прямолинейно подходит к `start`. |
| `draw_rectangle(start, width, height, plane="xy")` | Замкнутый прямоугольник от угла в положительных направлениях выбранной плоскости. |
| `draw_square(start, side, plane="xy")`, `draw_triangle(start, side, plane="xy")` | Квадрат и равносторонний треугольник. |
| `draw_circle(start, radius, segments=72, plane="xy")` | Окружность из отрезков; `start` лежит на окружности, не в центре. |
| `color_sensor(enabled=True, *, port, version)` | Настраивает датчик; `port="GP2"` и `version=1` или `2` выбирает оператор. |
| `read_color()` | Читает `(R, G, B)`, три целых 0–255, без движения. |
| `watch_color(handler, *, interval=0.1, stop_event=None, changes_only=True)` | Опрос с вызовом обработчика на первом показании и при изменениях. |
| `speed(percent)` | Задаёт один процент для скорости и ускорения PTP, от 1 до 100. |
| `home()` | Запускает поиск исходного положения и ждёт исполнения в очереди. |
| `suck(True)`, `suck(False)` | Включают и отключают присоску. Вызовы `suction_on()` и `suction_off()` сохранены для совместимости. |
| `gripper_open()`, `gripper_close()`, `gripper_off()` | Открывают, закрывают или отключают управление схватом. |
| `stop()` | Принудительно останавливает и очищает очередь. |
| `clear()` | Сбрасывает аварийные флаги и проверяет их обратным чтением. |
| `close()` | Освобождает порт. |

Перед первым действием с очередью (движение, скорость, homing, присоска или схват)
библиотека останавливает и очищает предыдущую очередь контроллера.
`calibrate()`, чтение RGB и немедленная настройка датчика этого не делают.
Открытие соединения читает координаты. `stop()` управляет очередью, `close()` освобождает порт,
а за выходы оснастки отвечают отдельные методы.
[Полные сигнатуры, побочные эффекты и ошибки каждого вызова](https://art9762.github.io/dobot-kit/api.html)

### Сброс ошибок контроллера

Если авария прервала движение, вызови `robot.stop()`. Устрани причину аварии, затем вызови `robot.clear()`. Если флаги остались активны, метод выбросит `RobotAlarmError` с их номерами в поле `alarms`. Чтобы продолжить движение, отправь новую команду.

### Управление присоской

С установленной присоской вызови `robot.suck(True)`, чтобы включить её. Когда предмет лежит на опоре, вызови `robot.suck(False)`, чтобы отключить присоску.

### Калибровка и рисование

`calibrate()` — программное сохранение начала отсчёта, **не homing и не аппаратная калибровка**.
Принимает `(x, y, z)` с сохранением текущего угла или `(x, y, z, angle)`.
Калибровка живёт только в данном объекте Python. До неё относительные движения дают `ValueError`.
`move_x(10)` дважды задаст один и тот же X; последовательность `move_x(10); move_y(5)`
даст X начала + 10 и Y начала + 5. `move_relative(dz=5)` возвращает X, Y и угол к началу
и задаёт Z начала + 5. После homing, смены инструмента или системы координат запиши начало заново.

`set_x(200)` физически перемещает X в **абсолютную** координату 200 мм, не в офсет
от калибровки. Аналогично `set_y(y)`, `set_z(z)` (мм) и `set_angle(angle)` (градусы).
Остальные оси берутся из текущей позиции перед движением; сохранённый `origin` не меняется.
Каждый вызов ждёт исполнения и сверяет позицию, как `move()`.
Это не переименование координат и не изменение нуля контроллера.

Для всех фигур `start` — абсолютная точка из трёх или четырёх чисел.
Три числа сохраняют угол, прочитанный в начале маршрута. `plane` — только именованный
аргумент: `"xy"`, `"xz"` или `"yz"`; размеры в мм, положительные.
У окружности центр находится на `radius` позади `start` по первой оси плоскости,
обход идёт к положительной второй оси, `segments` — целое от 12 до 720.

**Рисование физически двигает руку**, в том числе прямым отрезком от текущей позиции к `start`.
Подъём пера, включение лазера и обход препятствий не выполняются. Сначала проверь оснастку,
высоту и весь маршрут на малой скорости. Геометрическая проверка не гарантирует достижимость
или отсутствие столкновений. Каждый отрезок дожидается индекса и двух показаний позиции:
окружность аппроксимирована и может идти с остановками, это не непрерывная интерполяция.
Ошибка или `stop()` прерывают весь маршрут без автоматического продолжения.

### Датчик цвета

Используется штатный датчик классического Magician, не отдельный Seeed-модуль.
`port` — `"GP1"`, `"GP2"`, `"GP4"` или `"GP5"`, `version` — поколение
**датчика**: 1 или 2, не прошивки и не робота. Они обязательны; доступность конкретного
сочетания проверь по документации оснастки. Например, V1-датчик на V2-роботе допускает GP2.
Настройка отправляется немедленно, не очищает, не запускает и не останавливает очередь движений.
Возврат означает ACK, не подтверждает наличие датчика или готовность измерения.
Чтение не имеет автоматического включения; нулевой RGB не считается признаком ошибки
или отсутствия предмета. Названия цветов и пороги библиотека не угадывает.
[Проверенный контракт и первичные источники](docs/color-sensor-research.md).

```python
from dobot_usb import Dobot


def on_color(rgb):
    print("RGB:", rgb)
    # Можно обработать сигнал здесь. return False завершает опрос.


with Dobot("COM3") as robot:
    robot.color_sensor(port="GP2", version=2)  # Только для реально такой оснастки!
    robot.watch_color(on_color)  # Ctrl+C — выйти; этот код сам руку не двигает.
```

`watch_color()` синхронен, не создаёт поток. `interval` — 0.01–60 секунд паузы после
чтения/обработки; полный период включает время USB и callback.
`changes_only=False` передаёт каждую выборку без фильтра, `stop_event` принимает
`threading.Event`. Точное сравнение RGB не устраняет шум. Обработчик должен сам
избегать опасных действий и долгих блокировок. Ошибки USB и обработчика не скрываются,
команды не повторяются. `stop()` останавливает движение, **не цикл опроса**;
`close()` не отключает датчик.

### Проверка на оборудовании

Примеры для запуска оператором входят в исходники выпуска.

```sh
python -m pip install -e .
python examples/check_robot.py --port COM3 position
python examples/check_robot.py --port COM3 color --sensor-port GP2 --sensor-version 2
python examples/check_robot.py --port COM3 motion --axis x --offset 2
```

`position` только читает и сохраняет калибровку. `color` настраивает указанный датчик
и печатает 10 показаний. `motion` требует отдельного подтверждения `MOVE`, задаёт
скорость/ускорение 5%, перемещает одну ось на офсет до 5 мм от начала и возвращает её.
Пример **оставляет настройку 5%**; сначала проверь свободный путь и готовность остановки.
При изменении позы после подтверждения пример отменяет запуск или возврат. [Исходники примера](https://github.com/art9762/dobot-kit/blob/v0.3.0a3/examples/check_robot.py)

## Совместимость и переход

Программы от 0.2.0a4 требуют переноса на API серии 0.3. При переходе с 0.3.0a2 прежние вызовы присоски продолжают работать. Поддерживаются линейное движение, homing, присоска и пневматический схват. Определение модели и выбор оснастки остаются за оператором.

Обмен по USB для `clear()` и `suck()` версии 0.3.0a3 проверен с имитацией контроллера. На Magician с прошивкой 4.0.3 ранее проверены управляющие команды версии 0.3.0a2. [Совместимость, миграция и границы проверки](https://art9762.github.io/dobot-kit/development.html)

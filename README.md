# Dobot Kit

Подключи классический **DOBOT Magician** по USB и управляй им из Python. Начни с чтения координат руки.

## 1. Установи библиотеку

Нужен Python 3.11 или новее. Открой терминал в скачанной папке `dobot-kit`, где лежит файл `pyproject.toml`. Команды из этого раздела вводи в терминале. Если видишь `>>>`, ты в редакторе команд Python. Введи `exit()`, чтобы вернуться в терминал.

**Windows** · в командной строке (`cmd`)

```bat
py -3 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install .
```

**macOS и Linux**

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
```

Точка в конце команды означает «установить из текущей папки». Первые две строки создают и включают отдельное окружение Python для проекта. Когда открываешь новый терминал, снова выполни команду активации из второй строки.

## 2. Найди порт робота

Включи питание Magician и подключи USB. Закрой DobotStudio или другую программу, если она уже подключена к руке. Следующая команда покажет порты в терминале.

```sh
python -m serial.tools.list_ports
```

Имя порта будет похоже на `COM3` в Windows, `/dev/cu.usbserial-1420` в macOS или `/dev/ttyUSB0` в Linux. Если портов несколько, сравни список с подключённым и отключённым кабелем. Для программы возьми точное имя порта, который появился после подключения.

## 3. Прочитай координаты

В папке `dobot-kit` создай текстовый файл `robot_test.py`. Вставь этот код и поменяй `COM3` на свой порт.

```python
from dobot_usb import Dobot

robot = Dobot("COM3")
print(robot.position())
robot.close()
```

Сохрани файл и запусти его в том же терминале.

```sh
python robot_test.py
```

На экране появятся четыре числа, например `(210.0, 0.0, 65.0, 0.0)`. Первые три числа — координаты `x`, `y`, `z` в миллиметрах. Последнее число — угол поворота насадки в градусах. Подключение проверяет ответ руки чтением координат. Вся программа работает в режиме чтения.

## 4. Попробуй движение

Освободи пространство вокруг руки и убедись, что от текущего положения она может подняться на 5 мм по прямой. Замени содержимое `robot_test.py` этим примером и укажи свой порт.

```python
from dobot_usb import Dobot

robot = Dobot("COM3")
robot.speed(10)
x, y, z, angle = robot.position()
robot.move(x, y, z + 5)
robot.close()
```

Снова запусти `python robot_test.py`. Команда `speed(10)` устанавливает скорость и ускорение перемещений на 10% от настроенных в контроллере значений. Строка с `position()` сохраняет текущие координаты в переменные. Команда `move(x, y, z + 5)` поднимает руку на 5 мм по прямой, сохраняя `x`, `y` и угол. `move()` ждёт завершения и сверяет точку по данным контроллера.

Перед первой командой управления библиотека останавливает очередь контроллера и очищает команды, оставшиеся от предыдущего запуска.

## Все команды

| Команда | Что делает |
| --- | --- |
| `Dobot("COM3")` | Подключается к указанному USB-порту. |
| `robot.position()` | Возвращает `x`, `y`, `z` и угол. |
| `robot.move(x, y, z)` | Перемещает по прямой в заданную точку, сохраняя угол. |
| `robot.move(x, y, z, angle)` | Перемещает по прямой и задаёт угол насадки. |
| `robot.speed(10)` | Задаёт скорость и ускорение перемещений в процентах от 1 до 100. |
| `robot.home()` | Запускает процедуру поиска исходного положения. Рука движется. |
| `robot.suction_on()` / `robot.suction_off()` | Включает или выключает присоску. |
| `robot.gripper_open()` / `robot.gripper_close()` | Открывает или закрывает схват. |
| `robot.gripper_off()` | Отключает управление схватом. Чтобы открыть его, вызови `gripper_open()`. |
| `robot.stop()` | Просит контроллер немедленно остановить движение и удалить ожидающие команды. |
| `robot.close()` | Только закрывает USB-соединение. |

Команды присоски и схвата рассчитаны на соответствующую установленную оснастку. Для отключения оснастки используй её команды. Если связь потеряна во время движения, проверь положение руки перед следующей командой. При опасности воспользуйся физической остановкой или выключи питание по инструкции к роботу.

## Если возникла ошибка

- **`ModuleNotFoundError`** · активируй `.venv` в том же терминале, из которого запускаешь файл, и выполни `python -m pip install .`.
- **Порта нет в списке** · проверь питание, USB-кабель и драйвер последовательного порта.
- **Порт не открывается** · проверь имя, права доступа к порту и закрой программу, которая его заняла.
- **Робот не отвечает** · проверь, что выбран порт Magician и рука находится в обычном режиме управления. Если ошибка случилась после отправки команды, проверь состояние робота. При открытом соединении вызови `robot.stop()` перед следующей командой управления. Если связь пропала, подключись заново после проверки руки.

Эта версия проверяется офлайн с имитацией USB-обмена. Проверка новой версии на физическом роботе ещё впереди.

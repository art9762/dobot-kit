## Смена инструмента

Заверши текущее задание и уложи удерживаемый предмет. Отключи выход предыдущего
инструмента перед заменой насадки. В обычном режиме `robot.tool.select("gripper")`
выбирает локальный профиль. Для установленной насадки задай **измеренное** смещение
её рабочей точки (TCP) в миллиметрах. Текущее смещение возвращает `get_offset()`.

```python
robot.tool.select("gripper")
robot.tool.offset(x=x_mm, y=y_mm, z=z_mm)
print(robot.tool.get_offset())
```

После смены TCP заново задай используемые точки захвата, касания или фокусировки.

## Перенос присоской или схватом

Установи пустую насадку, задай подходящую скорость и обучи две точки с тем же
смещением TCP, с которым будешь работать. Сохрани `pick = robot.pose()` у
предмета и `place = robot.pose()` в точке укладки. Обе команды также принимают
`Point(x, y, z, r)` с XYZ в миллиметрах и R в градусах.

```python
robot.suction.pick_and_place(pick, place, lift_mm=10)
```

Для установленного схвата вызов выглядит так.

```python
robot.gripper.pick_and_place(pick, place, lift_mm=10)
```

Подбери `lift_mm` под свою рабочую зону. Высота перехода равна наибольшему Z
старта, захвата и укладки плюс этот подъём. Проверь, что весь путь свободен и
достижим с предметом в захвате. На время переноса передай управление рукой
одному сценарию. Метод дожидается предыдущих команд этой сессии
и считывает стартовую позу. Активный выход присоски, схвата или лазера прерывает
запуск до первой команды движения или переключения насадки.

Рука поднимается вертикально над текущим XY, подходит сверху к предмету и укладке
и заканчивает над точкой укладки. Каждое движение подтверждают два показания позы
контроллера. Присоска включается в точке захвата и выключается в точке укладки.
Схват раскрывается перед подходом, закрывается на предмете, открывается в точке
укладки и отключает управление после подъёма. При ошибке метод прекращает выдачу
команд. Перед следующим запуском проверь положение руки и удерживаемого предмета.

Пример с присоской предлагает обучить обе точки с помощью кнопки Unlock.
Пример со схватом принимает уже измеренные координаты.

```sh
python examples/pick_and_place.py
python examples/gripper.py --port PORT --pick X1 Y1 Z1 R1 --place X2 Y2 Z2 R2 --lift-mm MM
```

Для отдельных действий доступны `suction.on()`, `suction.off()`, `gripper.open()`,
`gripper.close()` и `gripper.release()`. Метод `state()` у каждой насадки читает
команду выхода контроллера. Физическое удержание предмета проверяет оператор.

## Линия лазером

Пример принимает явный порт и смещение конца линии `--by DX_MM DY_MM`.
Перед запуском выставь фокус в начале линии и подходящую скорость. Траектория лежит
на текущей высоте Z. Пример проверяет выключенный выход перед началом, включает его
на один отрезок и запрашивает выключение в блоке `finally`. Завершение проверяет
по состоянию выхода и позе контроллера. Подставь свой порт и размеры отрезка.

```sh
python examples/laser.py --port PORT --by DX_MM DY_MM
```

`robot.stop()` останавливает и по умолчанию очищает очередь движения. Инструменты
имеют отдельные выходы. Для лазера используй `off()` для выключения, `state()` для
чтения состояния и `disarm()` для отзыва локального разрешения. При разрыве связи
состояние излучателя неизвестно. Закрытие клиента освобождает порт.

## Что проверено на устройстве

На Magician 4.0.3 оператор подтвердил два отдельных штриха и рисунок «67» на бумаге.
Размеры следа инструментально не измерялись. Для присоски, схвата и лазера проверены
команды и ответы в программных тестах. Физическое удержание, отпускание и гравировка
этими примерами ещё требуют проверки.

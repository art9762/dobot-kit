Dobot Kit

Управление классическим DOBOT Magician по USB из Python 3.11 и новее.

Установка

Включи Magician и подключи USB. В терминале открой папку с исходниками dobot-kit и выполни две команды в окружении Python. Вторая перечислит доступные порты.

python -m pip install .
python -m serial.tools.list_ports

Первый запуск

Сохрани код в файл robot_test.py и замени COM3 своим портом.

from dobot_usb import Dobot

robot = Dobot("COM3")
print(robot.position())
robot.close()

Запусти программу в терминале. Она прочитает координаты и угол насадки.

python robot_test.py

Инструкция по движению и оснастке лежит в файле README.md в той же копии проекта.

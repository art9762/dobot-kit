Первое подключение

Установи Dobot Kit, подключи классический DOBOT Magician по USB и прочитай координаты руки из Python.

Установка

Открой терминал в своём окружении с Python 3.11 или новее. Команда установит dobot-usb с PyPI и pyserial для работы с портом.

Терминал
pip install dobot-usb
Как создать окружение Python

В папке проекта создай окружение и активируй его. Затем выполни команду установки выше.

macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
Windows PowerShell
py -m venv .venv
.\.venv\Scripts\Activate.ps1

Подключение по USB

Подключи руку в стандартном режиме Magician. Закрой DobotStudio или другую программу, которая использует её порт. Выведи список портов:

Терминал
dobot ports

Скопируй значение device нужного устройства. На Windows оно выглядит как COM3. Если рук несколько, при первом подключении определи порт каждой по очереди. Если список пуст, проверь USB-кабель и появление устройства в системе.

Чтение координат

Сохрани код в arm.py и запусти python arm.py. Вставь имя своего порта, когда программа попросит. Режим read_only=True позволяет прочитать состояние без движения руки.

arm.py
from dobot_usb import Dobot

port = input("Порт руки: ").strip()
with Dobot.connect(port, read_only=True) as arm:
    state = arm.status()
    print("Прошивка:", state.device.firmware)
    print("XYZ, мм:", state.pose.x, state.pose.y, state.pose.z)
    print("Ошибки:", state.alarms)

Программа выведет версию прошивки, три координаты в миллиметрах и ошибки, о которых сообщает контроллер. Пустой кортеж () означает, что активных ошибок он не сообщает.

Документация Dobot Kit

Python-библиотека для управления классическим DOBOT Magician по USB. Версия 0.3.0a2, Python 3.11 и новее.

Справочник APIВсе вызовы, аргументы, единицы, результаты и возможные ошибки. Поведение и диагностикаОчередь, состояние после ошибки, восстановление связи и ограничения проверки. USB-протоколКадры и ответы, коды команд, таймауты, порядок обмена и проверка позиции. Начало работыУстановка, выбор порта, первое чтение, перемещение и оснастка. Совместимость и разработкаВерсии Python, история оборудования, миграция, тесты и выпуск пакета.

Установка

python -m pip install dobot-usb==0.3.0a2
python -m serial.tools.list_ports

Первая команда устанавливает предварительный выпуск, вторая показывает имена портов. Подставь имя порта своего робота. Дополнительные шаги для Windows, macOS и Linux есть в руководстве по подключению.

Чтение координат

from dobot_usb import Dobot

robot = Dobot("COM3")
print(robot.position())
robot.close()

position() возвращает четыре числа в порядке x, y, z, angle. Первые три выражены в миллиметрах, угол в градусах. Скрипт только читает данные контроллера.

Что поддерживает эта версия

Перемещение по прямой, поиск исходного положения, настройка процентов скорости и ускорения, управление присоской и пневматическим схватом, остановка и закрытие соединения.

Перед первым управляющим вызовом текущего подключения библиотека останавливает и очищает очередь, оставленную предыдущим сеансом. Подробности и последствия для уже принятой команды описаны в разделе об очереди.

0.3.0a2 меняет API предыдущей серии. Для существующих программ смотри таблицу перехода. Текущая версия прошла проверку с имитацией USB-обмена. Физическая проверка описана отдельно в статусе совместимости.

Практическое руководство

Начни с чтения координат своего Magician. Затем выбери пример для нужной операции. Сохрани каждый пример в отдельный файл Python и подставь имя своего порта вместо COM3.

Установка

Для работы нужны классический четырёхосевой DOBOT Magician, его питание и USB-кабель для передачи данных. Установи Python 3.11 или новее и открой терминал в папке, где будут лежать программы для робота. Если терминал показывает >>>, введи exit(), чтобы вернуться из Python.

Windows

Открой командную строку cmd. Если используешь Windows Terminal, выбери профиль «Командная строка». Первая команда показывает версию Python.

py -3 --version
py -3 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install dobot-usb==0.3.0a4

macOS и Linux

python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install dobot-usb==0.3.0a4

.venv хранит Python-окружение для этого проекта. После открытия нового терминала снова выполни команду активации для своей системы. Если нужно выбрать конкретный установленный Python, укажи его при создании окружения, например py -3.12 -m venv .venv или python3.12 -m venv .venv.

Имя пакета для установки — dobot-usb. В файле Python используется from dobot_usb import Dobot. Проверь версию в том же окружении, из которого будешь запускать программы.

python -m pip show dobot-usb

Как выбрать USB-порт

  1. Включи питание Magician и подключи USB. Закрой DobotStudio и другие программы, которые могли занять порт.
  2. Выполни следующую команду в терминале. Она выводит имена последовательных портов и их описания.
python -m serial.tools.list_ports -v

Если портов несколько, сравни список до и после подключения кабеля, пока программы управления закрыты. В программе укажи точное имя появившегося порта.

СистемаПример имени
WindowsCOM3
macOS/dev/cu.usbserial-1420
Linux/dev/ttyUSB0 или /dev/ttyACM0

Операционная система может выдать другое имя после подключения к новому USB-разъёму. При ошибке открытия сначала обнови список портов. Подробности об ошибках и правах доступа есть в разделе о подключении и диагностике.

Первый запуск с чтением координат

Создай в рабочей папке текстовый файл robot_test.py, вставь код и замени COM3 своим портом. Имя файла должно заканчиваться на .py.

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    print(robot.position())
python robot_test.py

Можно увидеть, например, (210.0, 0.0, 65.0, 0.0). Первые три числа — координаты x, y и z в миллиметрах. Последнее — угол насадки в градусах. Значения относятся к системе координат робота и его текущей конфигурации. Подключение и position() читают данные контроллера. close() освобождает порт.

Блок with закрывает USB-соединение и при штатном выходе, и при исключении. Управление оснасткой и остановка выполняются отдельными командами.

Первое движение с подъёмом на 5 мм

Освободи рабочую зону, проверь крепление насадки и выбери исходное положение с запасом по высоте. Весь отрезок на 5 мм вверх должен быть достижим и свободен от препятствий. Все примеры движения запускай, находясь рядом с роботом и имея доступ к штатной физической остановке.

Сохрани пример в lift.py и выполни python lift.py после подстановки своего порта.

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    robot.speed(10)
    x, y, z, _ = robot.position()
    robot.move(x, y, z + 5)
    print(robot.position())

speed(10) задаёт 10% от настроенных в контроллере значений скорости и ускорения для перемещений от точки к точке. Координаты у move() абсолютные, поэтому для подъёма к текущей высоте прибавляется 5. Когда четвёртый аргумент опущен, сохраняется текущий угол. После подтверждения цели программа напечатает показания контроллера. Настройка скорости и ускорения сохранится после выхода из программы.

Перед первым действием с очередью библиотека останавливает её и удаляет прежние команды. В этом примере подготовку запускает speed(10). Запускай пример после окончания предыдущих работ и при единоличном управлении роботом.

Начало отсчёта и движение по оси

calibrate() запоминает текущую позицию в объекте Python. После этого move_z(3) задаёт высоту на 3 мм выше сохранённой и сохраняет текущие X, Y и угол. При повторном вызове цель по Z будет той же. Для абсолютной высоты можно вызвать set_z(z) без калибровки.

Проверь свободный путь на 3 мм вверх и обратно. Пример возвращает Z на исходную высоту.

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    robot.speed(5)
    origin = robot.calibrate()
    robot.move_z(3)
    print("После подъёма:", robot.position())
    robot.set_z(origin[2])

Для цели сразу по четырём координатам есть move_relative(dx, dy, dz, dangle). Каждое смещение отсчитывается от origin, а пропущенная величина равна нулю. При новом подключении начало нужно задать снова.

Квадрат в воздухе

Выбери положение над поверхностью, в котором весь квадрат со стороной 4 мм свободен в направлениях +X и +Y. Пример начинает в текущей позиции, проходит четыре стороны в плоскости XY и возвращается в исходный угол.

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    start = robot.position()
    robot.speed(5)
    robot.draw_square(start, side=4, plane="xy")

Для прямоугольника вызови draw_rectangle(start, width, height). При передаче другой начальной точки рука сначала идёт к ней по прямой. Высоту над бумагой, опускание и подъём пера задаёт твоя программа. Пример настраивает скорость и ускорение на 5%.

Запись и повторение двух позиций

Сохраняй точки с реального робота, чтобы повторить конкретную операцию на своём столе. Зафиксируй основание, оснастку и положение рабочей поверхности. При изменении любой из этих настроек запиши точки заново.

Запись в файл

Сохрани пример в save_point.py и укажи свой порт. В штатной программе контроллера осторожно подведи руку в первую позицию. Дождись остановки, отключи штатную программу от порта и запусти python save_point.py. Введи a, чтобы сохранить позицию в point_a.json. Проделай то же для точки b. Повторная запись под тем же именем заменяет сохранённые числа.

import json
from pathlib import Path

from dobot_usb import Dobot

port = "COM3"
name = input("Имя точки (a или b) > ").strip()
if name not in {"a", "b"}:
    raise ValueError("Введи a или b")

with Dobot(port) as robot:
    point = robot.position()

path = Path(f"point_{name}.json")
path.write_text(json.dumps(point), encoding="utf-8")
print(path, point)

Повторение записанных точек

Перед запуском убедись, что рабочая зона осталась прежней. Проверь, что прямые от текущей позиции до a и от a до b свободны. Если для переноса требуется обойти препятствие, запиши отдельные точки над ним и проверь каждый отрезок, включая подъём и спуск.

Сохрани программу в replay.py. Оба файла с точками должны лежать в рабочей папке терминала. В строке robot.move(*point) звёздочка передаёт четыре сохранённых числа как отдельные аргументы.

import json
import math
from pathlib import Path

from dobot_usb import Dobot


def load_point(filename):
    point = json.loads(Path(filename).read_text(encoding="utf-8"))
    if type(point) is not list or len(point) != 4:
        raise ValueError(f"В {filename} должно быть четыре числа")
    if any(type(value) not in (int, float) or not math.isfinite(value) for value in point):
        raise ValueError(f"Проверь числа в {filename}")
    return point


points = [load_point("point_a.json"), load_point("point_b.json")]

with Dobot("COM3") as robot:
    robot.speed(10)
    for point in points:
        robot.move(*point)
        print(robot.position())

Проверка файла отсеивает неподходящие данные. Достижимость точки, зазоры для насадки и свободу всех отрезков проверяет оператор. Движение выполняется последовательно, поэтому при ошибке выполнение цикла прервётся. Перед следующей попыткой проверь, где остановилась рука.

Присоска и пневматический схват

Проверь установленную оснастку, подключение, крепёж и свободное пространство прежде, чем подавать команды. Начни с испытания без предмета над свободной поверхностью. Команды отрабатывают через очередь контроллера. Захват и удержание предмета проверяй визуально.

Проверка присоски

Сохрани код в suction.py и запусти python suction.py. Пока программа ждёт Enter, проверь состояние присоски, оставаясь вне рабочей зоны.

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    robot.suck(True)
    try:
        input("Проверь присоску и нажми Enter для выключения ")
    finally:
        robot.suck(False)

Принимаются значения Python True и False. Справочник по присоске.

Проверка схвата

Сохрани код в gripper.py и запусти python gripper.py. Проверь движение губок без предмета, держа руки вдали от оснастки. gripper_off() отключает управляющий выход. Чтобы разжать губки, используй gripper_open().

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    robot.gripper_open()
    input("Проверь раскрытие и нажми Enter для закрытия ")
    robot.gripper_close()
    input("Проверь закрытие и нажми Enter для открытия ")
    robot.gripper_open()
    robot.gripper_off()

Как спланировать перенос предмета

  1. Запиши четыре позиции на своём столе. Нужны точки захвата и укладки, а также точки подхода над каждой из них. Выбери высоту прохода с учётом насадки и предмета.
  2. Пройди маршрут без предмета на малой скорости. Проверь прямые отрезки между позициями. Если нужны дополнительные точки обхода, запиши и проверь их заранее.
  3. Подойди к предмету сверху, опустись в точку захвата и включи присоску либо закрой схват. Убедись, что предмет удерживается. Поднимись вертикально до точки подхода.
  4. Перемести предмет в точку над местом укладки, опусти его на опору и только после этого отпусти. Подними насадку в свободное положение.

При штатном завершении выключи присоску или открой и отключи схват после размещения предмета. При обрыве связи или прерывании программы оснастка может сохранить состояние. Сначала проверь руку и груз, затем выполни контролируемое восстановление. Остановка, ошибки и восстановление

Получение RGB

Выбери разъём и поколение установленного датчика. Этот пример рассчитан на штатный датчик V1 в GP2. Его обработчик получит три показания подряд, включая одинаковые, и завершит опрос.

from dobot_usb import Dobot

samples = []

def collect(rgb):
    samples.append(rgb)
    print(rgb)
    return len(samples) < 3

with Dobot("COM3") as robot:
    robot.color_sensor(port="GP2", version=1)
    try:
        robot.watch_color(collect, interval=0.2, changes_only=False)
    finally:
        robot.color_sensor(False, port="GP2", version=1)

Для одного показания после настройки достаточно rgb = robot.read_color(). Результат содержит три числа от 0 до 255. Проверь отклик на образцах при своём освещении, прежде чем использовать RGB для выбора действия.

Сброс ошибки контроллера

Если авария прервала движение, останови свой сценарий. Оставь один процесс владельцем USB-порта. Следующий пример оператор запускает отдельно для восстановления. Он останавливает очередь и запрашивает подтверждение перед сбросом.

from dobot_usb import Dobot
from dobot_usb.errors import RobotAlarmError

with Dobot("COM3") as robot:
    robot.stop()
    if input("Устрани причину аварии. Введи CLEAR для сброса: ").strip() == "CLEAR":
        try:
            robot.clear()
        except RobotAlarmError as error:
            print("Активные коды:", error.alarms)
            raise
        print("Контроллер сообщил, что аварийные флаги сняты.")

Если соединение оборвалось во время записи, результат команды может быть неизвестен. Проверь состояние руки и оснастки перед новой командой. Восстановление после сбоя.

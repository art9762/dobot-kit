Инструменты

У классического Magician пять штатных насадок. Первые четыре работают через connect(). Для печатающей головки есть отдельный клиент Printer.

После смены насадки проверь смещение её рабочей точки (TCP) и заново запомни нужные позы. Перед движением закрой другие программы управления, выбери скорость под задачу и выясни, какие команды остались в очереди. Если старое задание можно отбросить, вызови arm.stop(clear=True) перед первым движением. Настройка смещения · Работа с очередью

Присоска

Пустой присоской покажи руке два места — где взять предмет и куда его положить. Подведи её к каждой точке кнопкой Unlock, отпусти кнопку и сохрани позу. Для переноса понадобится свободный путь выше самой высокой из трёх поз — стартовой, захвата и укладки.

Python
from dobot_usb import connect

port = input("Порт руки: ").strip()
with connect(port) as arm:
    input("Присоска в точке захвата? Нажми Enter. ")
    pick = arm.pose()
    input("Присоска в точке укладки? Нажми Enter. ")
    place = arm.pose()
    lift_mm = float(input("На сколько мм подняться над точками? "))
    if input("Путь свободен. Запустить перенос? [да/нет] ") == "да":
        arm.suction.transfer(pick, place, lift_mm)

Рука подходит сверху, включает вакуум у предмета, отпускает его в точке укладки и поднимается. После ошибки проверь, где находится предмет и удерживает ли его присоска. Скрипт переноса с обучением точек

Пневмосхват

Запомни две позы теми же шагами, что и для присоски. Для захвата подведи раскрытые губки по сторонам предмета. В программе выше замени последнюю строку вызовом для схвата.

Python
arm.gripper.transfer(pick, place, lift_mm)

Схват раскрывается перед подходом, сжимает предмет в точке захвата и раскрывается после укладки. Для ручного управления есть open() и close(). Вызов release() отключает управление губками. Скрипт для известных координат

Перо

Закрепи лист и подведи кончик пера до лёгкого касания. Эта поза станет началом рисунка. Каждая пара чисел в штрихе — смещение по X и Y в миллиметрах от точки касания.

Python
from dobot_usb import connect

strokes = [[(0, 0), (5, 0)], [(0, 2), (5, 2)]]
with connect(input("Порт руки: ").strip()) as arm:
    paper = arm.pose()
    report = arm.draw(strokes, paper, dry_run=True)
    print(report.completed_points)

dry_run=True физически проводит перо над листом. Для рисунка верни кончик в точку касания перед повторным запуском и убери аргумент dry_run=True. Рука проведёт две линии длиной 5 мм, приподнимая перо между ними и после последней. Маршрут, расчёт без движения и отчёт

Лазер

Сначала прочитай состояние выхода контроллера. Этот скрипт открывает порт только для чтения.

Python
from dobot_usb import connect

with connect(input("Порт руки: ").strip(), read_only=True) as arm:
    state = arm.laser.state()
    print("Управление включено:", state.enabled)
    print("Выход активен:", state.active)

arm.laser.arm() даёт программе разрешение на включение в текущем сеансе. За выход отвечают on() и off(). Остановка движения и закрытие порта оставляют управление выходом отдельной задачей. При потере связи состояние излучателя проверяют на установке. Порядок работы с лазерной головкой

3D-печать

Печатающей головке нужна принтерная прошивка Magician. Настрой головку и ноль стола по руководству Dobot, затем открой её порт через Printer. Для первой проверки достаточно узнать температуру сопла.

Python
from dobot_usb import Printer

port = input("Порт принтера: ").strip()
with Printer.connect(port) as printer:
    print("Температура сопла, °C:", printer.temp().current_c)

Для печати нарежь модель с профилем Magician и проверь слои в слайсере. В том же блоке with вызови printer.print("part.gcode"). Метод проверит команды файла и начнёт передавать задание принтеру. Протокол обмена проверен программно. Физическая печать и совместимость прошивки конкретного экземпляра пока требуют проверки. Формат задания, поддерживаемые команды и работа с Cura

Периферия

Дополнительная оснастка доступна через то же соединение arm в стандартном режиме Magician. Выбери группу по установленному устройству.

  • Рельс. arm.rail.position() возвращает положение в миллиметрах. При движении указывают и позицию рельса, и полную целевую позу руки. Методы рельса
  • Конвейер. После измерения числа шагов на миллиметр укажи его в arm.conveyor.configure(). Тогда run() принимает скорость ленты в мм/с. Калибровка и управление
  • Датчики. arm.sensors.color() читает RGB, а ir(port) — состояние ИК-датчика. Перед чтением укажи порт и версию подключённого модуля в его настройках. Настройка датчиков
  • Входы и выходы. Через arm.io выбирают режим пина, читают цифровой вход и АЦП, управляют цифровым выходом и ШИМ. Методы I/O

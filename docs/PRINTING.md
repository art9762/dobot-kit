# Печать штатным экструдером Magician

## Прямая печать из Python

Подготовьте штатную головку, переведите Magician в **3D Printer Firmware** и задайте ноль рабочего стола согласно руководству. Нарежьте модель с профилем Magician. Передайте программе путь к текстовому `.gcode` и порт именно этого контроллера. Порт должен быть свободен для подключения. [Dobot Magician User Guide V1.7.0, §5.9](https://download.dobot.cc/product-manual/dobot-magician/pdf/V1.7.0/en/Dobot-Magician-User-Guide-V1.7.0.pdf)

```python
from dobot_usb import Printer

port = input("Порт принтера: ").strip()
with Printer.connect(port) as printer:
    print(printer.firmware, printer.temp().current_c)
    result = printer.print("part.gcode")
    print(result.path.name, result.acknowledged_commands)
```

`connect()` открывает выбранный порт на 115200 бод и запрашивает идентификацию (`M115`) и температуру сопла (`M105`). Прямая передача рассчитана на текстовый RepRap-протокол версии 1 с распознаваемым именем прошивки семейства Marlin, Sprinter, Repetier или Dobot. Ответ `M105` должен содержать температуру первого хотэнда. `temperature()` возвращает текущую температуру `current_c` и заданную `target_c`, если прошивка её сообщает. Код не устанавливает прошивку и не использует механизм сброса DTR из настроек Repetier-Host. [Dobot, табл. 5.16](https://download.dobot.cc/product-manual/dobot-magician/pdf/V1.7.0/en/Dobot-Magician-User-Guide-V1.7.0.pdf) · [M115](https://marlinfw.org/docs/gcode/M115.html) · [M105](https://marlinfw.org/docs/gcode/M105.html)

`print_file()` сначала разбирает **весь** файл и сохраняет проверенные команды во временном файле. При ошибке синтаксиса или неподдерживаемой команде исключение `ValueError` указывает строку, ни одна команда задания в порт не уходит. Затем клиент запрашивает `M400` для проверки готовности планировщика, передаёт команды по одной и ожидает `ok` после каждой. Итоговый `PrintResult` возвращается только после отдельного подтверждения заключительной `M400`. Это подтверждение контроллера о завершении запланированных перемещений. Качество детали, подачу пластика и температуру после печати оценивает оператор. [Последовательный обмен Marlin](https://marlinfw.org/docs/features/host_interface.html) · [Завершение движений M400](https://marlinfw.org/docs/gcode/M400.html)

Прямой режим принимает числовые параметры обычного слайсера для одного экструдера.

| Команды | Назначение |
| --- | --- |
| `G0`, `G1`, `G2`, `G3`, `G4` | Перемещения, дуги и пауза |
| `G21`, `G90`, `G91`, `G92`, `M82`, `M83`, `T0` | Миллиметры, координаты и режим экструдера |
| `M104`, `M109` | Уставка первого сопла, допустимый диапазон файла 0–250 °C |
| `M106`, `M107` | Вентилятор |
| `M117`, `M84` | Короткий ASCII-текст на дисплее и отключение двигателей по явной строке файла |
| `M140 S0`, `M190 S0`, `M400` | Нулевая уставка стола, ожидание планировщика |

Штатные профили Cura включают сообщение `M117 Printing...` и завершающую команду `M84`. В профилях Slic3r используется компактная запись движений. Оба варианта читаются напрямую. [Архив профилей Dobot для Repetier-Host и Cura](https://download.dobot.cc/DobotStudio-pro/20230706/3D%20Printing%20Slicing%20Parameters%20for%20Reptier-Host%20%26%20Cura.rar)

Укажите нагрев и последующее отключение нагрева непосредственно в профиле слайсера. В руководстве Dobot приведён завершающий сценарий с отключением нагревателя. Границы рабочего стола, положение нуля, скорость, температуры материала и физическую траекторию проверяйте в профиле Magician. Команды с номерами и контрольными суммами, хоминга, записи в память, сценариев хоста и произвольного текста остаются за пределами этого режима. Нормализованная строка вместе с переводом строки укладывается в консервативный бюджет 63 байта, выбранный по настройке приёмного буфера в руководстве. [Dobot Magician User Manual V1.2.5, §§8.2.2 и 8.4](https://download.dobot.cc/product-manual/dobot-magician/pdf/en/dobot-magician-user-manualV1.2.5.pdf)

По умолчанию срок получения ответа на обычную команду — 5 секунд (`Printer.connect(port, timeout=...)`), для нагрева с ожиданием, пауз и `M400` — 300 секунд (`printer.print(path, wait_timeout=...)`). Клиент прекращает отправку и закрывает порт при ошибке протокола, потере связи, неизвестном результате записи или запросе повтора. Квитанции предыдущих строк сохраняют своё значение. Сообщение `PrinterError` указывает, на каком этапе прервалось задание и сколько строк подтвердил контроллер. Вызов `close()` из другого потока или прерывание текущего задания прекращает дальнейшую передачу. Установленная температура и уже принятые движения могут сохраняться. При обрыве проверьте на оборудовании положение и нагрев перед следующим заданием.

Руководство Dobot подтверждает режим прошивки, скорость порта и профиль RepRap (Marlin/Sprinter). Формат запросов и подтверждений прямого клиента проверен тестами обмена. Фактический ответ `M115` и выполнение `M400` конкретным экземпляром печатной прошивки Magician требуют аппаратной проверки. Ответ о семействе прошивки сам по себе не идентифицирует модель устройства.

## Открытие в Cura или Repetier-Host

Если уже есть нарезанный для Magician файл `.gcode`, Python может открыть его в программе печати. На macOS руководство Dobot указывает Cura. На Windows поддерживаются Repetier-Host и Cura. Установите выбранное приложение отдельно и укажите путь к нему. [Dobot Magician User Guide V1.7.0, §5.9](https://download.dobot.cc/product-manual/dobot-magician/pdf/V1.7.0/en/Dobot-Magician-User-Guide-V1.7.0.pdf)

```python
from dobot_usb.printing import open_print_job

job = open_print_job("part.gcode", application="/Applications/UltiMaker Cura.app")
print(job.motion_commands, job.extruder_moves)
```

Для Windows замените `application` на полный путь к установленному исполняемому файлу хоста, например `r"C:\Program Files\Repetier-Host\RepetierHost.exe"`. Хост открывает исходный файл со всеми параметрами слайсера. В окне предварительного просмотра проверьте выбранный профиль Magician и слои, затем запустите печать средствами хоста. Возврат `open_print_job()` подтверждает передачу запроса операционной системе. Статус загрузки и ход печати показывает сам хост. [Форматы файлов Cura](https://support.ultimaker.com/articles/Knowledge/1667411286871) · [Готовый G-code из внешнего слайсера в Repetier-Host](https://www.repetier.com/documentation/repetier-host/slicing/)

Для физической печати необходимы штатный комплект экструдера и хотэнда, режим **3D Printer Firmware** и настроенный в хосте профиль Magician. Перед подключением через хост закройте активное соединение `Dobot` с тем же портом. В руководстве указан последовательный порт принтера и **115200 бод**. Для Repetier-Host указан автоматический выбор протокола передачи. Выбор порта, соединение, установка нуля, температурный режим и запуск задания выполняются в программе печати. Библиотека передаёт ей только путь к файлу. Конкретную установленную версию хоста и физический принтер нужно проверить вместе. [Dobot Magician User Guide V1.7.0, §5.9.2–5.9.3, рис. 5.129 и табл. 5.16](https://download.dobot.cc/product-manual/dobot-magician/pdf/V1.7.0/en/Dobot-Magician-User-Guide-V1.7.0.pdf)

## Содержимое задания

```python
from dobot_usb.printing import inspect_gcode

job = inspect_gcode("part.gcode")
print(job.path, job.commands, job.motion_commands, job.extruder_moves)
```

`inspect_gcode()` читает файл построчно. `commands` считает строки команд G/M/T. `motion_commands` считает команды G0–G3 с координатами или параметрами дуги, включая движения одного экструдера. `extruder_moves` считает такие команды с параметром E, включая ретракты и подачу перед печатью. Для оценки количества пластика или геометрии используйте предпросмотр слайсера.

Принимаются обычные текстовые файлы `.gcode`. Комментарии, номера строк, компактная запись параметров и файлы с переводами строк Windows поддерживаются. Пустой маршрут, двоичные данные или некорректная запись чисел перемещения вызывают `ValueError`. Строки сценариев хоста с префиксом `@` или `;@` также требуют открытия непосредственно в программе печати. Инспекция проверяет структуру файла. Совместимость конкретных команд с версией прошивки, пределы перемещений и параметры нагрева проверяются отдельно. [Команды хоста в документации Repetier](https://www.repetier.com/documentation/repetier-host/gcode-editor/)

Справочник API

Dobot управляет классическим четырёхосевым Magician по USB. Вызовы синхронные. XYZ и размеры задаются в миллиметрах, угол насадки — в градусах, время — в секундах.

Подключение и чтение позиции

Dobot(port: str)

Передайте точное непустое имя порта, например COM3 в Windows или /dev/ttyUSB0 в Linux. Конструктор открывает порт и проверяет связь чтением позиции. Если проверка завершается ошибкой, он освобождает порт. Имена доступных портов выводит python -m serial.tools.list_ports.

Сеанс with

from dobot_usb import Dobot

with Dobot("COM3") as robot:
    x, y, z, angle = robot.position()
    print(x, y, z, angle)

При входе __enter__() возвращает тот же объект. При выходе __exit__() вызывает close(). Исключение из блока передаётся вызывающему коду. В следующих фрагментах robot обозначает уже открытый экземпляр.

position() -> tuple[float, float, float, float]

Читает одну текущую выборку (x, y, z, angle). Метод доступен и после stop(), пока порт открыт. Неверная длина ответа или значения NaN и бесконечности дают ProtocolError. Во время движения значения могут меняться между двумя чтениями.

close() -> None

Освобождает порт, повторный вызов допустим. Закрытие оставляет контроллер исполнять уже принятые команды. Чтобы остановить их или отключить оснастку, вызовите соответствующие методы при открытом порте.

Калибровка и координаты

calibrate(position: Sequence[float] | None = None) -> tuple[float, float, float, float]

Возвращает и запоминает начало отсчёта для относительных перемещений. Без аргумента читает все четыре координаты. Для тройки (x, y, z) берёт угол из текущей позиции. Для четвёрки (x, y, z, angle) сохраняет заданные числа без чтения USB. Калибровка изменяет только сохранённую позу в этом объекте. Для воспроизводимого начала считывайте позу после остановки. После смены инструмента или homing при необходимости сохраните новое начало.

origin -> tuple[float, float, float, float] | None

Свойство только для чтения. Возвращает сохранённый кортеж без обращения к USB. Новый экземпляр начинает со значения None.

saved = robot.calibrate()
print(robot.origin == saved)  # True

Абсолютное перемещение

move(x: float, y: float, z: float, angle: float | None = None) -> None

Перемещает насадку по прямой к координатам контроллера. Если угол пропущен или равен None, метод читает текущий угол, затем проверяет аварийные флаги и отправляет цель. Положение руки, достижимость цели и свободный ход насадки вдоль всего отрезка проверьте до запуска.

x, y, z, angle = robot.position()
robot.move(x, y, z + 2)  # Подъём на 2 мм с текущим углом

Для координат, углов и размеров допустимы конечные значения int и float, представимые в float32. Значения bool, строки и выход за числовой диапазон приводят к ValueError. Физическую точность оценивают внешним измерением. Как библиотека проверяет достижение цели.

Изменить одну абсолютную координату

set_x(x: float) -> None
Задаёт абсолютную X в миллиметрах.
set_y(y: float) -> None
Задаёт абсолютную Y в миллиметрах.
set_z(z: float) -> None
Задаёт абсолютную Z в миллиметрах.
set_angle(angle: float) -> None
Задаёт абсолютный угол насадки в градусах.

Каждый метод сначала считывает текущую позу, заменяет выбранное значение и выполняет линейное перемещение. Остальные три координаты цели берутся из этого чтения. Методы доступны до калибровки. Например, robot.set_z(50) задаёт высоту 50 мм в системе контроллера.

Смещения от сохранённого начала

move_x(offset: float) -> None
Задаёт X равной origin[0] + offset в миллиметрах.
move_y(offset: float) -> None
Задаёт Y равной origin[1] + offset в миллиметрах.
move_z(offset: float) -> None
Задаёт Z равной origin[2] + offset в миллиметрах.
move_angle(offset: float) -> None
Задаёт угол равным origin[3] + offset в градусах.
move_relative(dx: float = 0, dy: float = 0, dz: float = 0, dangle: float = 0) -> None
По всем четырём осям прибавляет аргументы к сохранённой позе. Пропущенное смещение равно нулю, поэтому по этой оси целью будет сохранённая координата.

Все пять методов требуют успешной калибровки. Иначе возникает ValueError до записи в порт. Четыре одноосевых метода сохраняют три остальные координаты текущей позы. Повтор одного и того же смещения задаёт то же значение выбранной координаты.

robot.calibrate()
robot.move_z(2)           # На 2 мм выше сохранённой Z
robot.move_relative()     # Вернуть все четыре координаты к калибровке

Отрезок и фигуры

Точки задаются абсолютными координатами в последовательности из трёх или четырёх чисел. Если для точки указан только XYZ, её угол берётся из одного чтения в начале маршрута. Четвёртое число задаёт угол этой точки явно. Размеры фигур должны быть положительными. Именованный аргумент plane принимает "xy", "xz" или "yz". Порядок букв определяет первую и вторую оси, третья координата сохраняется.

draw_line(start: Sequence[float], end: Sequence[float]) -> None
Переходит к start, затем по прямой к end. Точки могут различаться по всем координатам.
draw_rectangle(start: Sequence[float], width: float, height: float, *, plane: str = "xy") -> None
Из начального угла откладывает ширину по положительной первой оси и высоту по положительной второй, обходит контур и возвращается в start.
draw_square(start: Sequence[float], side: float, *, plane: str = "xy") -> None
Рисует замкнутый квадрат со стороной side. Начальный угол и направление обхода совпадают с прямоугольником.
draw_triangle(start: Sequence[float], side: float, *, plane: str = "xy") -> None
Строит равносторонний треугольник. Первая сторона направлена по первой оси, третья вершина смещена к положительной второй оси. Последний отрезок возвращает в start.
draw_circle(start: Sequence[float], radius: float, *, segments: int = 72, plane: str = "xy") -> None
Начальная точка лежит на окружности. Центр находится на radius позади неё по первой оси. Обход начинается к положительной второй оси и заканчивается в начальной точке. segments задаёт число отрезков, целое от 12 до 720 включительно.

Подход к началу фигуры также выполняется по прямой. Высоту пера и состояние инструмента задаёт оператор. Путь проверяется на числовую корректность до подготовки очереди. Достижимость и зазоры зависят от оборудования. Каждый отрезок отдельно дожидается индекса и подтверждения позы. При сбое или stop() оставшиеся отрезки отменяются.

start = robot.position()  # Рука уже находится на выбранной высоте
robot.draw_rectangle(start, width=4, height=2, plane="xy")

Скорость и поиск исходного положения

speed(percent: float) -> None
Задаёт одинаковый процент скорости и ускорения PTP. Диапазон от 1 до 100 включительно, допустима дробная часть. Например, robot.speed(5) задаёт 5% обоих коэффициентов. Метод ожидает индекса и оставляет настройку в контроллере.
home() -> None
Запускает процедуру поиска исходного положения, определённую прошивкой, и ждёт её исполнения в очереди. До отправки проверяет аварийные флаги. Для фактических конечных XYZ и угла считайте position() после возврата. Значение origin сохраняется.

Присоска и пневматический схват

Эти команды завершаются, когда индекс контроллера достигает заданного значения. Проверяйте захват и удержание по установленной оснастке. Для отпускания сначала опустите предмет на опору.

suck(enabled: bool) -> None
robot.suck(True) включает выход и присоску, robot.suck(False) отключает оба флага. Принимаются только два значения Python типа bool. Метод доступен с 0.3.0a3.
suction_on() -> None
Совместимый вызов suck(True).
suction_off() -> None
Совместимый вызов suck(False).
gripper_open() -> None
Включает выход схвата и подаёт команду раскрыть губки.
gripper_close() -> None
Включает выход схвата и подаёт команду сомкнуть губки.
gripper_off() -> None
Отключает выход схвата. Конечное положение губок зависит от механики.

Программы для отдельной проверки присоски и схвата приведены в руководстве. Примеры для пневматики.

Датчик цвета

color_sensor(enabled: bool = True, *, port: str, version: int) -> None

Включает или отключает штатный датчик цвета. Для enabled передайте True или False. Именованные аргументы port и version обязательны. Поддерживаются строки "GP1", "GP2", "GP4", "GP5" и целые поколения датчика 1 или 2. Для датчика V1 на Magician V2 производитель указывает GP2. Выберите разъём и поколение по маркировке оснастки. Метод дожидается подтверждения немедленной записи. Очередь движений при этом сохраняется. Совместимость и формат обмена.

read_color() -> tuple[int, int, int]

Возвращает три целых числа (R, G, B), каждое от 0 до 255. Для измерения сначала настройте подключённый датчик. Пакет другой длины вызывает ProtocolError. Нулевая выборка допустима. По одному ответу нельзя установить наличие датчика, свежесть измерения или название цвета.

watch_color()

watch_color(
    handler: Callable[[tuple[int, int, int]], bool | None],
    *,
    interval: float = 0.1,
    stop_event: threading.Event | None = None,
    changes_only: bool = True,
) -> None

handler принимает один кортеж RGB. По умолчанию вызов происходит при первом чтении и каждом точном изменении тройки. Аргумент changes_only принимает только bool. При False обработчик получает каждое чтение. interval задаёт паузу после чтения и обработки от 0,01 до 60 секунд включительно. Укажите stop_event типа threading.Event, чтобы остановить опрос из другого потока. Уже установленное событие завершает метод до первого чтения.

Опрос выполняется в вызывающем потоке до установки события или возврата именно False из обработчика. None продолжает цикл. Исключения обработчика, USB и KeyboardInterrupt передаются вызывающему коду. Метод stop() управляет очередью движения. Чтобы отключить датчик, вызовите color_sensor(False, ...) с его разъёмом и поколением.

# Для датчика V1, установленного на GP2
samples = []

def collect(rgb):
    samples.append(rgb)
    return len(samples) < 3

robot.color_sensor(port="GP2", version=1)
try:
    robot.watch_color(collect, interval=0.1, changes_only=False)
    print(samples)
finally:
    robot.color_sensor(False, port="GP2", version=1)

Остановка и сброс аварий

stop() -> None

Принудительно останавливает очередь и удаляет ожидающие команды. Метод ждёт подтверждений обеих операций. Он может прервать команду из другого потока и разрешает дальнейшие управляющие вызовы после ошибки принятой команды. Выходы пневматики сохраняют своё состояние. При сбое остановки или очистки соединение закрывается. Состояние руки и оснастки после такого сбоя проверьте на месте.

clear() -> None

Доступен с 0.3.0a3. Если авария прервала движение, вызовите robot.stop(). Устраните причину и вызовите robot.clear(). Метод отправляет немедленный сброс и проверяет флаги обратным чтением. Он возвращает None, когда набор флагов пуст. При сохранении флагов возникает RobotAlarmError. Поле alarms содержит их номера, stage равно "accepted", так как контроллер уже подтвердил запись сброса. Для движения требуется новая команда оператора.

Очередь и подтверждение результата

Перед первым движением, home(), speed(), командой пневматики или clear() экземпляр сначала останавливает и очищает прежнюю очередь контроллера. Успешный явный stop() также выполняет подготовку. Калибровка, чтение телеметрии и настройка датчика цвета обходятся без такой подготовки. Один порт и его очередь должны принадлежать одной программе.

ОперацияКак проверяется выполнение
Движение к одной точке, включая подход к фигуреАварийные флаги проверяются до отправки. После принятия команды библиотека запускает очередь при необходимости. До 30 с отводится на отправку и достижение индекса. Затем за отдельные 5 с нужны два последовательных показания, близких к цели и друг к другу. Допуск по XYZ — 0,3 мм по расстоянию, по углу — 0,65° по абсолютной разности.
Homing, скорость и пневматикаАварийные флаги проверяются при ожидании индекса. Для homing есть также проверка перед отправкой. Время на отправку и достижение индекса — до 60 с для homing и 30 с для остальных. Дополнительного чтения конечной позы или состояния оснастки эти методы не выполняют.
Немедленные записиНастройка датчика возвращается после подтверждения. Сброс аварий дополнительно читает флаги. Сами записи выполняются вне очереди.

Один обмен по USB ограничен одной секундой. Подготовка очереди, ожидание доступа и отдельные чтения занимают дополнительное время. Сроки для движений относятся к каждому отрезку. По одной квитанции о приёме команды нельзя определить фактическую точность движения или удержание детали. Порядок обмена и форматы пакетов.

Ошибки и восстановление

Неверное значение аргумента даёт ValueError. Пропущенный обязательный или неизвестный аргумент вызывает TypeError. Ошибки связи и исполнения наследуются от dobot_usb.errors.DobotError.

ConnectionError, RequestTimeout
Порт недоступен, связь потеряна или истёк срок обмена. При потере ответа запись могла дойти до контроллера. Библиотека не повторяет её автоматически.
ProtocolError
Неожиданный кадр, формат данных или индекс очереди. Ошибки транспортного обмена закрывают соединение.
RobotAlarmError
Маска контроллера содержит активные флаги. Поле alarms — кортеж номеров. Сверьте их с документацией прошивки.
ExecutionTimeout, CommandInvalidated
Истёк срок операции либо ожидание потеряло связь со своей очередью вследствие остановки или закрытия.

stage и его псевдоним outcome указывают этап затронутой операции. not_sent означает, что запрос ещё не отправлен, хотя подготовка уже могла пройти. sent_unconfirmed означает отправку без подтверждения, accepted — получение подтверждения контроллера, unknown — недостаток сведений. command, queue_index и session_id заполняются по доступным данным.

from dobot_usb.errors import RobotAlarmError

# После устранения причины аварии и остановки прерванного движения
try:
    robot.clear()
except RobotAlarmError as error:
    print("Активные аварии:", error.alarms)
    raise

После сбоя уже принятой команды дальнейшее движение в этом сеансе требует явного stop(). После потери связи сначала проверьте фактическую позу и оснастку, затем откройте новое соединение. Восстановление после сбоя.

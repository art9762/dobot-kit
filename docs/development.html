Совместимость и разработка

В 0.3.0a4 обновлена документация. Публичный API совпадает с 0.3.0a3. Ниже приведены версии Python для CI, результаты проверок с контроллером и порядок сборки пакета.

Устройства и окружение

КомпонентКонтракт 0.3.0a4
МодельКлассический четырёхосевой DOBOT Magician со стандартным последовательным протоколом. Для Magician Lite, E6 и других семейств нужен их собственный интерфейс.
ПодключениеПоследовательный порт по USB, указанный оператором. Один владелец порта и очереди контроллера.
ОснасткаШтатные присоска и пневматический схват, датчик цвета с выбранными разъёмом и поколением. Для пассивного пера библиотека строит пути перемещения. Высоту над поверхностью задаёт оператор.
PythonПакет устанавливается с Python 3.11 и новее. Матрица CI проверяет 3.11–3.14 на Ubuntu и 3.12 на Windows и Intel macOS.
Зависимость во время работыpyserial==3.5. Пакет Python и модуль импорта называются соответственно dobot-usb и dobot_usb.
Форматы дистрибутиваУниверсальный wheel py3-none-any и архив исходников .tar.gz. Для доступа к порту используются драйверы операционной системы.

Статус проверки оборудования

Версия и условияЧто проверили
0.3.0a3, имитация USBДля wheel и исходного архива с PyPI отдельно прошли 283 теста. Среди них проверка байтов включения и отключения присоски, оставшихся аварийных флагов после сброса и потери подтверждения. Новые методы clear() и suck() на реальном роботе в этом выпуске не испытывались. CI для тега 0.3.0a3.
0.3.0a2, Magician 4.0.3 с ручкой27 ноября 2026 г. по USB вызвали все 29 публичных методов. Контроллер сообщил координаты для движения по осям, фигур в воздухе, остановки и homing. Для прежних вызовов присоски и схвата прочитали флаги выходов. На пустом GP2 получили трёхбайтовые отчёты RGB. Удержание предмета, распознавание цвета и точность рисунка физически не измеряли.
Более ранняя реализацияНа прошивке 3.7.0 контроллер сообщил о достижении восьми целей в воздухе. На 4.0.3 оператор видел штрихи на бумаге. Архивный отчёт относится к указанным в нём реализации и оснастке.

Переход с предыдущих версий

С 0.3.0a3. Обнови пакет обычной командой python -m pip install --upgrade dobot-usb==0.3.0a4. Сигнатуры и поведение методов сохранены.

С 0.3.0a2. Вызовы suction_on() и suction_off() продолжают работать. В новых сценариях можно использовать suck(True) и suck(False). Для сброса аварийных флагов после устранения причины доступен clear().

Документация 0.2.0a4

Устройство исходников

src/dobot_usb/__init__.py и _robot.py
Публичный класс, проверки параметров, синхронные операции и сверка координат после перемещения.
geometry.py
Проверка координат, выбор плоскости и расчёт точек фигур.
execution.py
Экземпляр очереди на одно соединение, подтверждения и индексы, ожидание, смена поколения при остановке.
transport.py и protocol.py
Настройка последовательного порта, отправка, проверка байтов и разбор ответа.
validation.py и errors.py
Проверка чисел перед обменом и ошибки со сведениями о том, дошла ли команда до контроллера.
tests/
Офлайн-проверки открытого API, исполнения, транспорта и формата кадров. Подмена serial.Serial обязательна для тестов.
examples/check_robot.py
Проверки с оператором в режимах position, color и motion. Пример входит в архив исходников. Режим position только считывает позу. Параметры всех режимов доступны через --help.
docs/
Редактируемые HTML-страницы и общий CSS. GitHub Pages публикует эту папку из main. Сохраняй ссылки на разделы, если меняешь заголовки.

Локальная проверка и сборка

Клонируй репозиторий, перейди в его папку и выбери тег нужного выпуска. Для тестов нужен checkout Git с каталогом tests/. Зависимости инструментов разработки зафиксированы в uv.lock.

git clone https://github.com/art9762/dobot-kit.git
cd dobot-kit
git switch --detach v0.3.0a4
uv sync --locked
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv build

uv build создаёт wheel и архив исходников в dist/. Для запуска примера из checkout используй uv run python examples/check_robot.py --help. Этот вызов выводит справку без обращения к USB.

При изменении публичного метода проверь вызов через from dobot_usb import Dobot и повтори его в тесте с подменой транспорта. Для записи проверь байты, обычное подтверждение и потерю подтверждения. Для движения отдельно проверяй реакцию на активную сигнализацию, продвижение индекса и совпадение координат.

Для аппаратного отчёта зафиксируй модель и прошивку, оснастку, сделанные вызовы, значения индексов и координат, наблюдение оператора и способ измерения. Удали серийные номера из публичного отчёта.

Выпуски и изменения

Версия в pyproject.toml и uv.lock совпадает с тегом без ведущей v. Wheel и архив исходников собираются из того же коммита, который указывает тег. Workflow publish.yml сверяет SHA-256 файлов GitHub Release и публикует их на PyPI через Trusted Publishing. Статус пакета, сайта и матрицы CI проверяется отдельно.

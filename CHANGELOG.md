# История изменений Dobot Kit

## 0.3.0a1 · 2026-11-19

Предварительный выпуск с изменением публичного API.

- Для подключения, линейного перемещения, поиска исходного положения, настройки скорости и управления штатной оснасткой используется класс `Dobot`.
- `position()` возвращает четыре числа. `move()` принимает абсолютные координаты, при пропущенном угле читает текущий и после исполнения сверяет два показания позиции.
- Первый управляющий вызов останавливает и очищает очередь. После ошибки уже принятого вызова следующий вызов управления требует явной остановки или нового подключения. Команды автоматически не повторяются.
- Удалены CLI, прежние группы API, автоматическое рисование, лазер, рельса, конвейер и 3D-печать. Название дистрибутива `dobot-usb` сохранено.
- Опубликованы полная спецификация API, руководство по USB-протоколу, описание исполнения и восстановления, примеры и таблица перехода.
- Автоматические проверки работают на имитации USB. Аппаратное подтверждение новой версии остаётся открытым.

[Справочник API](https://art9762.github.io/dobot-kit/api.html) · [Переход с 0.2.0a4](https://art9762.github.io/dobot-kit/development.html#migration)
